# MathHelpper — Помощник учителя математики 📐

Современное веб-приложение (PWA) для проведения уроков математики, подготовки к ОГЭ/ЕГЭ и интерактивной работы с учениками на интерактивной панели, ноутбуке или планшете.

---

## 🚀 Основные возможности

### 1. 🎨 Интерактивная доска (Whiteboard)
- **Pointer Events**: полная поддержка мыши, стилуса (графический планшет, Apple Pencil, S-Pen) и мультитача.
- **Инструменты**: перо со сглаживанием Безье, полупрозрачный маркер-выделитель, стирающий ластик.
- **Фигуры**: отрезки, векторы со стрелками, прямоугольники, окружности, треугольники, координатные оси $X/Y$ с делениями, текстовые блоки.
- **Полотно**: бесконечный холст, плавное панорамирование (инструмент «Рука» или зажатое колесико) и масштабирование (zoom).
- **Сетки**: тетрадная клетка (5 мм), миллиметровка, точечная сетка или чистый лист.
- **История и экспорт**: отмена/повтор (`Ctrl+Z` / `Ctrl+Y`), автосохранение в браузере, экспорт в PNG и копирование в буфер обмена.

### 2. 📈 Построитель графиков (Plotter / Desmos-style)
- Одновременное построение любого количества графиков с индивидуальными цветами.
- **Интерактивные ползунки параметров**: задавайте $y = a \cdot x^2 + b \cdot x + c$ или $y = k \cdot x + b$ — приложение автоматически определит переменные $a, b, c, k$ и создаст ползунки с кнопкой плавной анимации (Play).
- **Авто-поиск ключевых точек**:
  - Нули функции (пересечения с осью $OX$).
  - Пересечение с осью $OY$ ($f(0)$).
  - Точки пересечения двух графиков (графическое решение систем уравнений).
- Таблица значений $f(x)$ с шагом по аргументу.
- Быстрые математические шаблоны: парабола, гипербола $\frac{1}{x}$, корень $\sqrt{x}$, модуль $|x|$, тригонометрия $\sin(x)$.

### 3. 📐 Динамическая геометрия (JSXGraph)
- Полнофункциональный движок интерактивной геометрии:
  - Точки, отрезки, прямые, лучи, окружности, многоугольники.
  - Перпендикулярная и параллельная прямые, середина отрезка, биссектриса угла, касательная.
  - Измерение расстояний и углов с отображением числовых значений на чертеже.
- **Готовые интерактивные теоремы**:
  - Вписанная и описанная окружности треугольника с центрами.
  - Теорема Пифагора с динамическим расчетом $a^2 + b^2 = c^2$.
  - Медианы треугольника и центроид (свойство деления $2:1$).

### 4. 💡 Пошаговый Решатель задач
- Решение школьных задач с подробным описанием каждого шага и формулами KaTeX:
  - **Квадратные уравнения**: вычисление $D = b^2 - 4ac$, нахождение корней, проверка по теореме Виета, разложение трехчлена на множители $a(x-x_1)(x-x_2)$.
  - **Линейные уравнения**: раскрытие, перенос слагаемых, деление на коэффициент.
  - **Квадратные и линейные неравенства**: метод интервалов, расстановка знаков, интервальный ответ.
  - **Системы 2×2 уравнений**: аналитическое решение и кнопка «Посмотреть на графике».
  - **Прогрессии**: нахождение $n$-го члена и суммы первых $n$ членов ($a_n, S_n, b_n$).
- Кнопка **«Случайный пример»** для мгновенной генерации задач прямо во время урока.

### 5. 📖 Шпаргалка / Справочник
- Разделы «Алгебра» и «Геометрия».
- Формулы сокращенного умножения, квадратные уравнения, теорема Пифагора, площади треугольников, свойства окружностей.
- Примеры применения и блок **«Частые ошибки на ОГЭ / ЕГЭ»**.
- Живой поиск по темам.
- Кнопки быстрой интеграции: переход из справочника прямо в построитель графиков или геометрический чертеж.

### 6. 📱 PWA, адаптивность и темы
- **PWA (Progressive Web App)**: работает офлайн, устанавливается на ПК, iPad или смартфон в один клик.
- Поддержка тем: Тёмная (для проектора или вечерней работы) и Светлая.
- Режим «Во весь экран» для интерактивной доски.

## 💻 Запуск проекта локально

1. Установка зависимостей (уже выполнена):
   ```bash
   npm install
   ```

2. Запуск в режиме разработки:
   ```bash
   npm run dev
   ```
   Откройте адрес `http://localhost:5173` в браузере.

3. Сборка для публикации:
   ```bash
   npm run build
   ```
